## Full description

### Arabic interface, familiar date and time digits

Prefer familiar Latin digits such as **29/10/2026** and **14:35** while using Odoo in Arabic? Arabic Numbers Fix requests Latin digits for locale-formatted dates and times in Arabic backend sessions. Arabic menus and translations remain Arabic, while other language sessions keep their normal formatting.

### Designed to stay lightweight

- Targets Arabic locale sessions in the Odoo backend.
- Applies to dates and times formatted through the backend locale formatter.
- Depends only on Odoo's standard Web module.
- Makes no external requests and collects no user data.

### Clear scope

This addon targets locale-formatted backend dates and times. It does not claim to rewrite every numeric field, arbitrary text, PDF report, export, website, or custom module. Those may use separate formatting components and should be validated independently. The addon does not change stored data, language, translations, or number separators.

### Compatibility

Separate packages are provided for Odoo 12.0 through 20.0. Install the package matching your Odoo series on a server where custom addons are enabled. This addon is not installable on Odoo Online (SaaS).
